# 🛡️ Jawara Basa Sunda X - Game Kuis Interaktif

**Jawara Basa Sunda X** adalah game edukasi interaktif berbasis web yang dirancang untuk membantu siswa Kelas X mempersiapkan ujian Bahasa Sunda. Seluruh soal disusun berdasarkan **25 indikator kisi-kisi resmi MA Madinatunnajah Tahun Pelajaran 2026/2027**.

---

## 🎮 Fitur Utama
- **Cakupan Materi Lengkap (25 Indikator):** Mencakup seluruh materi dari kisi-kisi ujian.
- **4 Variasi Tipe Soal:**
  1. **Pilihan Ganda (PG):** Soal analisis konsep dan sejarah.
  2. **Pilihan Ganda Kompleks (PGK):** Memilih lebih dari satu pernyataan yang benar.
  3. **Benar / Salah:** Menguji ketelitian pemahaman materi.
  4. **Menjodohkan:** Mencocokkan istilah, unsur intrinsik, dan fungsi rarangkén.
- **Ilustrasi & Aksara Sunda Baku:** Dilengkapi ilustrasi SVG bertema budaya Sunda serta dukungan karakter Unicode **Aksara Sunda** (`Noto Sans Sundanese`).
- **Mekanisme Permainan Menantang:** Dilengkapi sistem 5 nyawa (❤️), penghitung skor otomatis, dan umpan balik/pembahasan langsung di setiap nomor soal.
- **Ringan & Responsif:** Dibangun menggunakan *Pure HTML, CSS, dan Vanilla JavaScript* dalam satu file tunggal tanpa perlu instalasi *library* tambahan.

---

## 📚 Materi yang Diujikan
1. **Niskala Wastu Kancana:** Tujuan perkawinan dengan Mayangsari dan kejayaan Karajaan Kawali.
2. **Carita Babad & Babad Galuh:** Asal-usul kata *babad*, unsur sejarah vs mitos (*pamohalan*), sikap kritis, dan nilai kepemimpinan.
3. **Ki Sayang Hawu:** Analisis unsur intrinsik (tema, alur/galur, dan sudut pandang/puseur sawangan).
4. **Aksara & Rarangkén Sunda:** Penulisan kata/kalimat, aturan gelar & tanda baca, penulisan nama jalan, serta fungsi rarangkén (*panghulu, panyecek, pamaéh, pamepet, panéléng, panyuku*).

---

## 🚀 Cara Menjalankan & Membuat Link (GitHub Pages)
1. Pastikan file utama di repositori ini diberi nama **`index.html`**.
2. Buka tab **Settings** pada repositori GitHub Anda.
3. Pilih menu **Pages** di bilah sisi kiri.
4. Pada bagian **Build and deployment** > **Branch**, pilih `main` (atau `master`) dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu 1–2 menit, dan link game publik Anda akan muncul di bagian atas halaman tersebut untuk langsung dibagikan kepada siswa!
